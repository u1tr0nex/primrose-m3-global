# Compatibility

## Confirmed

| Component | Tested version |
| --- | --- |
| Device | Xiaomi 14 Ultra (`aurora`) |
| Firmware | HyperOS 3.0.302.0.WNAINXM, Android 16 |
| Camera | Xiaomi Camera 6.4.00530.0 / PrimroseCam base |
| Gallery | Global Gallery 4.3.1.6 |
| Media Editor | 2.4.0.5.2 |
| Root | KernelSU Next |
| Hook runtime | Vector LSPosed 2.2 |

## Not claimed

No compatibility is claimed for other Xiaomi devices, China ROMs, different Gallery or Media Editor versions, future firmware builds, Magisk/Zygisk variants, or other Xposed implementations.

## Image-quality policy

The setup preserves the tested HyperOS 1 imaging-engine tuning profile for supported still-photo paths and does not upscale M3 files to claim 50 MP. Genuine 50 MP M3 output requires a separate native/vendor imaging-pipeline effort.
