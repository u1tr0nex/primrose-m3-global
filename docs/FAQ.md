# FAQ

## The M3 entry is missing

Verify LSPosed scope, force-stop Camera and Gallery, then reopen Camera. Confirm you are using the tested camera and firmware combination.

## Gallery frames show an unsupported-photo message

Use a newly captured Essential/M3 photo after updating the companion module in place. Ensure Media Editor is included in LSPosed scope, then force-stop Gallery and Media Editor.

## Does this provide genuine 50 MP M3 captures?

No. Current M3 output is 4096 × 3072. Enlarging the JPEG would not create genuine sensor detail, so that was intentionally not shipped.

## Does this hide root or Xposed from banking apps?

No. This project does not provide detection-evasion functionality. Keep camera modification separate from apps that require a trusted device state.
